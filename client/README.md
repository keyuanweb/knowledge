# client（企业知识库问答前端）

## 1. 安装依赖
- `npm install`

## 2. 运行开发环境
- `npm run dev`

## 3. 后端地址
默认请求：`http://localhost:5000/api`

如需修改，可在项目根目录创建 `.env`：
- `VITE_API_BASE_URL=http://localhost:5000/api`
